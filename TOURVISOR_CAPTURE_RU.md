# Как снять реальный запрос Tourvisor

Нужно один раз поймать запрос, который сайт отправляет при поиске туров. После этого мы заменим временную карту параметров в `src/providers/tourvisorApiProvider.ts` на точную.

## В Chrome

1. Открой `https://tourvisor.ru/search.php`.
2. Нажми `F12`.
3. Перейди во вкладку `Network`.
4. Включи фильтр `Fetch/XHR`.
5. Заполни поиск: город вылета, страна, даты, ночи, туристы, питание, бюджет.
6. Нажми поиск.
7. Найди запрос, который возвращает список туров или цены.
8. Правый клик по запросу -> `Copy` -> `Copy as cURL`.

Секреты, cookies и персональные токены лучше не отправлять в чат целиком. Достаточно:

- URL без приватных токенов;
- query parameters;
- 1 короткий пример JSON/XML ответа на один тур;
- названия полей цены, отеля, даты, питания, ссылки.

## Что мы после этого сделаем

- настроим точные параметры Tourvisor;
- добавим справочники городов/стран/питания, если API требует ID вместо названий;
- включим реальный provider вместо `demo`;
- прогоним тестовый поиск;
- задеплоим worker через Docker на постоянный сервер.
